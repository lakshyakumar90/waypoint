# Waypoint Engineering + DSA Plan

A React + Vite learning dashboard that combines the 40-day engineering sprint and the 60-day DSA track. Day 1 is November 1, 2026; the engineering sprint ends December 10 and the DSA track ends December 30.

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. For a production build, run `npm run build`.

Progress is stored in browser localStorage on the current browser/device.

## What's inside

- `src/data.js`: 40 engineering days, 165 DSA practice prompts, revision checkpoints, and documentation links.
- `src/App.jsx`: dashboard, filters, DSA status controls, daily plan, visual traces, topic map, project audit cards, and resource drawer.
- `src/style.css`: responsive dark dashboard styling.

## DSA note

The Waypoint DSA sheet contains 165 questions. This companion plan includes 165 conventional interview-practice prompts organized by pattern. Open the linked Waypoint site to compare or rename any titles that differ from the current sheet.
